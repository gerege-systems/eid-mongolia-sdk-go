# eid-mongolia-sdk-go

**eID Mongolia** relying-party SDK for Go — иргэнийг утсаар нь нэвтрүүлэх ба хууль ёсны цахим гарын үсэг
зуруулах (RP-API v3, Smart-ID нийцтэй), «eID-ээр нэвтрэх» (OpenID Connect).

Баримт: <https://developer.eidmongolia.mn/>. TypeScript хувилбар:
[gerege-systems/eid-mongolia-sdk](https://github.com/gerege-systems/eid-mongolia-sdk).

> Хөгжүүлэлт явагдаж байна — анхны хувилбар `v0.1.0`.
